# Urban Routes — Automação de Testes

Projeto de automação de testes web desenvolvido durante o programa **QA Engineer da TripleTen**.

##  Tecnologias

- Python
- Selenium WebDriver
- Pytest
- Page Object Model
- Git
- GitHub

##  Sobre o projeto

O projeto teve como objetivo automatizar cenários de teste da aplicação web Urban Routes, validando diferentes funcionalidades e comportamentos da aplicação.

##  O que foi desenvolvido

- Automação de cenários de teste para a aplicação web.
- Organização do código utilizando o padrão Page Object Model.
- Criação de funções auxiliares para facilitar a reutilização do código.
- Execução e validação dos testes automatizados.

##  Estrutura do projeto

- `main.py` — execução dos testes
- `pages.py` — elementos e métodos das páginas
- `helpers.py` — funções auxiliares
- `data.py` — dados utilizados nos testes
- `requirements.txt` — dependências do projeto
